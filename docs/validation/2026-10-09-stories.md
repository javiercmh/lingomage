## Reproduction without deleting a signed-in installation

Build APKs with `assembleDebug assembleDebugAndroidTest`, install both using
`adb install -r`, then run selected tests through `adb shell am instrument`.
Avoid the Gradle connected runner on a signed-in installation because it can
uninstall the target app after its run. Test databases use unique names and are
removed afterward; production credentials are never reset by these tests.

`LiveGenerationTest` is skipped unless explicitly enabled with
`-e live_generation true`. It consumes the selected account's ChatGPT plan and
saves sample stories. `-e class ...LiveGenerationTest#exportSavedSamples -e
live_export true` exports existing public-topic samples without inference.
Never export tokens, authorization URLs, or credential files.

## Okurigana follow-up

The user reported an apparent repeated `ます` in Japanese furigana. The original
prompt allowed whole inflected-word readings. Japanese prompt version .2 now
requests readings over kanji only, and the renderer uniquely aligns written kana
in existing annotations. Regressions cover 行きます, 食べます, 読みます, 白い,
お母さん, 食べ物, preserved 学校/友達 compounds, extra duplicated ます and
ambiguous alignment. Debug build, unit tests and lint passed after this correction.
The updated large-font device test passed, and one Japanese prompt-.2 sample
completed, validated, saved and exported successfully. It contains 行/い,
読/よ, 飲/の, and preserved 学校/がっこう compounds with plain kana endings.
The change does not prove every AI reading correct.
